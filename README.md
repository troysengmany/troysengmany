## Featured Projects

### [STM32 Gesture-Controlled Smart Home](https://github.com/troysengmany/stm32-gesture-controlled-smart-home)

Real-time gesture interface using Python, OpenCV/MediaPipe, UART, and STM32 control for LED brightness, fan speed, a servo-driven smart door, and OLED feedback.

### [STM32 Hand-Tracking LED Dimmer](https://github.com/troysengmany/stm32-hand-tracking-led-dimmer)

Computer-vision LED dimmer that uses hand tracking and pinch distance to control three independent STM32 PWM channels over UART.

### [Arduino Snake Game](https://github.com/troysengmany/arduino-snake-game)

Joystick-controlled Snake game on an 8x8 LED matrix with movement timing, collision detection, food generation, and dynamic snake growth.

### [Arduino LED Matrix Display](https://github.com/troysengmany/arduino-led-matrix-display)

Arduino/MAX7219 display project featuring custom 8x8 bitmap letters, scrolling text, bit shifting, and iterative display experiments.
